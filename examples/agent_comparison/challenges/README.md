observations.json retains independent agent acceptance and every blocked tool attempt. The
earlier supported-case corpus/observations remain unchanged in the parent directory.

stale notebook outputs and mutation-sensitive shared-object fanout. All three agents passed
independent acceptance. All three tool conversions were blocked with no project published.

and engine rules were not relaxed, and original inputs were not rewritten after the failures.

Use the parent README's materialization approach with this corpus and a NEW isolated destination;
these frozen prompts use generated/challenging-agent-comparison-v1/<case_id> paths. Substitute
only the repository/output layout for repeats. Preserve original input strings and inventory
identities. Detailed local candidates, logs and checker are not product APIs or included here.
