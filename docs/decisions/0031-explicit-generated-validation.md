# ADR 0031 - Explicit validation of generated notebook test snapshots

Date: 2026-11-24

Status: accepted

## Context

The interface presents declarations and unexecuted checks, while running delivered tests requires
manual commands. Users need one explicit runtime choice, bounded execution and evidence linked
to the reviewed project. Static generation and historical/pilot execution consent must stay distinct.

## Decision

Add a separate shared prepare/run boundary for generated notebooks with supplied regression tests.
Recompute the existing renderer, require matching generated bytes and bind a deterministic review
identity to settings, inputs, inventory, interpreter, budget, attempt path and worker policy/source.
Require that exact identity again before creating an exclusive attempt or starting a subprocess.

Run the fixed delivered suite on a private copy using an existing selected Python. Record available
distribution metadata, bounded logs/JUnit and durable terminal outcomes, with cancellation and
worker process-group/tree cleanup. Validate captured identities afterwards. Do not install packages,
rewrite source/tests/oracles, alter generation reports or merge these results with imported runs.

API and CLI own execution/snapshot rules. VS Code 0.4.0 composes selection, read-only review,
explicit confirmation, graceful cancellation, summary and log presentation. Existing static local
envelopes stay unchanged. The first slice is notebook-only; functional execution needs separate scope.

## Consequences

One supplied-test run becomes reviewable and reproducible within recorded limits. Passing requires
positive tests and unchanged captured files, and establishes neither scientific acceptance nor
full type/schema/business coverage. The copy is not a security sandbox; no disk quota, package-lock
verification, whole-host effect policy or authenticated evidence is claimed. Preparation/copying and
cleanup are outside the worker timeout. Concurrent mutation and forced-disconnect limits stay explicit.
Existing human/provider/pilot consent contracts remain independent and unapproved by this feature.
